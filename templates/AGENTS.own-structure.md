# Agent instructions

Read README.md, docs/project-structure.md, docs/requirements.md and docs/features/ before changing code.
This project keeps its own structure; the owner chose that. Follow the conventions in
docs/project-structure.md: put new code beside similar code, match the naming and test style
nearby, and do not move, rename or reorganise existing files.
Use `make tasks` to see what is backlog, in progress, completed or rejected.
Move tasks with `make task-move`, never by hand.
Run `make check` before reporting work done.
`make structure-check` lists placeholders to fill; it does not enforce a layout here.
