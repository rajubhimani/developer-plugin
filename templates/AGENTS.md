# Agent instructions

Read README.md, docs/requirements.md and docs/features/ before changing code.
Use `make tasks` to see what is backlog, in progress, completed or rejected.
Move tasks with `make task-move`, never by hand.
Run `make check` before reporting work done.
The project kind and layout rules are in `.developer-plugin/project.json` and
`docs/architecture.md`; `make structure-check` enforces them. Do not move or restructure
code to satisfy it without the owner's approval.
